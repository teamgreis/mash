# Research Notes

Pre-design comparisons and exploration notes preserved for context. These
documents informed the protocol's early design decisions but are **not part
of the shipped specification**. They are excluded from the rendered MkDocs
site (see `exclude_docs:` in `mkdocs.yml`).

If a topic in this directory has been settled, the conclusion lives in
`docs/decision-log.md` (look for the `DEC-XXX` reference) or in the relevant
normative document under `docs/`.
